# Catalog staging bundles

Files here are deterministic, review-only inputs for `catalog_staging`. They
are versioned so extracted records and their source locators are saved remotely
without committing vendor PDFs or page images.

Rules:

- bundles must end in `needs_review`;
- bundles must not contain approved/promoted candidates or promotion batches;
- every source mention must retain record-level provenance;
- a bundle is not application data and must not be imported by browser code;
- source PDFs remain in the gitignored `catalogs/` workspace;
- manual page images must not be published until reuse permission is confirmed;
- use `scripts/catalog/stage-manual-bundle.mjs` for database writes, and target
  an explicitly approved staging database only.

`degelman-pro-till-ptl4652.json` is generated by
`scripts/catalog/build_degelman_pro_till_staging.py` from official Degelman
manual `143433` revision `v1.3`. Rebuild and run its integrity test before
committing any change.
